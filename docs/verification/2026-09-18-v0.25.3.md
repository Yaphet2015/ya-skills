[标签工作流](https://github.com/Yaphet2015/ya-skills/actions/runs/35312825900) 因发现已上传产物而跳过后续步骤，状态为 success。`ci.json` 保留各步骤状态。这不代表 CI 执行了测试；发布依据是上述本地检查。

## 发布操作

先提交并推送 Skill，再提交并推送签名修复、回归检查和版本号。打标签前核对工作树干净，HEAD 与远程 main 均为测试提交。通过 `gh release create v0.25.3 --target adfc444320b0f3d69d5de6cc9087c9d069dd2f11` 上传压缩包和 `.sha256`，没有覆盖旧版本。

重新下载并比对通过后，使用 `scripts/update-ya-skills-formula.py` 更新公式 URL、哈希和版本断言，再提交推送 tap。Homebrew 升级时设置 `HOMEBREW_NO_INSTALL_CLEANUP=1`，保留旧版本供排查。

发布证据与产物分开保存。本次压缩包、编译文件以及解压和下载目录在所有检查通过后清理；GitHub Release 保留可下载产物。
