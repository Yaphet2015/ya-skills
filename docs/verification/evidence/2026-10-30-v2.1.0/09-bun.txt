Function domains: demo, pbench, computer-use, computer-e2e
Run 'yk <domain> -h' to list actions, 'yk <domain> <action> -h' for usage.

2.1.0
a-share-data      Fetch A-share quotes, K-lines, and filings. Use when the user asks for A-share market data.
bankai            Explicitly launch or resume tasks in any Git repository with persistent evidence and interruption recovery.
coding-recon      Use when ownership, contracts, callers, or root cause are unclear before a non-local code change.
computer-e2e      Deterministic macOS desktop E2E via yk. Use only when the user asks for computer-e2e. · computer-use
computer-use      Route web pages through browser DOM/CDP first, then drive native macOS UI when a visible desktop app is required.
design-grill      Stress-test a design or plan. Use when the user wants to grill an idea, PRD, or architecture.
eli10             Finer-grained explanation of a diagnosis or mechanism. Use after 看不懂 / 太费劲 / 再详细解释.
eli5              Picture-heavy HTML explainer. Use only when the user asks for eli5.
pbench            Deprecated. PBench capture/replay. Use when a coding-agent outcome is wrong, or the user asks to capture, run, or compare runs.
plan-jury         Sol/Grok/GLM plan review. Use only when the user invokes plan-jury.
produce           Subagent Plan → independent challenge → implementation with simplify per part → testing. Discuss technical choices with Main; consult users on UX.
repro             Generate manual acceptance steps from a diff, with expected and before-change behavior, evidence, and optional mock setup. Use for /repro or human QA handoffs.
show-pr           Use only when the user explicitly invokes show-pr to build an offline Chinese PR HTML report; never triggers implicitly.
stage             Read-only repository task status, automatically including same-project sibling repositories when present. · bankai
svg-icons         Unified SVG icon/glyph. Use when the user invokes /svg-icons or asks for an icon.
ui-parity         Align existing UI surfaces or extract shared interactions with baseline regression checks, state comparisons, and rendered evidence. Use for UI parity work.
ultra-cr          Independent risk-assigned code review with batch verification, evidence-filtered findings and script-managed resumable reports.
ultra-produce     Deprecated. Coordinate native Planner, Builder and Verifier subagents with file-based handoffs, stage hooks and local commits. · ultra-cr
ultra-simplify    Use when the user asks for a massive simplification pass
validator         Deprecated. Plan Completion Standard. Use only when the user invokes /validator after a Plan is complete.
video-transcript  Video transcript (captions first, Whisper fallback). Use when the user wants text from a video.
